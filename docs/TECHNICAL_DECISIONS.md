# Decisiones Técnicas - LangGraph

## Uso de LangGraph

Se selecciona LangGraph como framework de orquestación para representar flujos de agentes mediante grafos de estados.

## Razón

Permite controlar:

- Estado de ejecución.
- Secuencia de agentes.
- Decisiones condicionales.
- Flujos complejos.

## Arquitectura multiagente

La separación de responsabilidades entre agentes permite crear componentes especializados y reutilizables.

## Evolución futura

- Integración con herramientas empresariales.
- Memoria persistente.
- Evaluación de agentes.
- Observabilidad.
- Agentes especializados en fraude y riesgo.
